cxxode 快速开始（3 步搞定）
================================

第 1 步：双击运行
-----------------
双击：quick-install.bat

看到 "安装完成！" 即可


第 2 步：重启终端
-----------------
关闭当前终端，打开新终端（CMD/PowerShell 都可以）


第 3 步：开始使用
-----------------
# 测试
ode --version

# 配置 API 密钥
ode login anthropic
# 输入: sk-ant-...

# 在任何目录使用
cd D:\任意项目
ode "帮我分析代码"


完成！
======
现在可以在任何文件夹打开终端，输入 ode 就能用了。

更多功能查看：docs/USAGE.md
