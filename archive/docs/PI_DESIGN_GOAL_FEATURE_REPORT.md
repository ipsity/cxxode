### 2. 命令面板增强（吸收 Pi 设计）

**新特性：**
- ✅ **快捷键显示** - 每个命令显示键盘快捷键
  - 例如：`/search [Alt+S]`
  - 例如：`/test [Alt+T]`
  
- ✅ **最近使用优先** - 智能排序
  - 最近使用的命令自动排在前面
  - 分数加成：最近的 +50, 次近的 +45...
  - 显示"── 最近使用 ──"分组

- ✅ **命令快捷键映射表**
  ```cpp
  /search, /s  → Alt+S
  /test, /t    → Alt+T
  /build, /b   → Alt+B
  /run, /r     → Alt+R
  /commit, /c  → Alt+C
  /help        → F1
  /clear       → Ctrl+N
  ```

**使用体验：**
```
输入 /
显示：
── 最近使用 ──
  /test 🧪 运行测试 [Alt+T]
  /search 🔍 搜索并查看 [Alt+S]
  
── Commands ──
  /goal 🎯 设置工作目标
  /ref 🔄 快速查看编辑
  ...
```

### 3. Dialog 渲染系统（吸收 Pi 设计）

**新增工具类：** `dialog_renderer.hpp`

**功能：**
- ✅ `render_box()` - 漂亮的边框对话框
  ```
  ╔════════════════════════════════╗
  ║ 标题                           ║
  ╟────────────────────────────────╢
  ║ 内容行 1                       ║
  ║ 内容行 2                       ║
  ╚════════════════════════════════╝
  ```

- ✅ `render_choice()` - 选择项渲染
  ```
  ▶ [1] 选项 A - 详情
    [2] 选项 B - 详情
  ```

- ✅ `render_confirm()` - 确认对话框
  ```
  ╔════════════════════════════════╗
  ║ 确认操作                       ║
  ╟────────────────────────────────╢
  ║ 确定要执行此操作吗？           ║
  ║                                ║
  ║ [Enter]  [Esc]                ║
  ╚════════════════════════════════╝
  ```

**设计理念（吸收自 Pi）：**
- 统一的视觉风格
- 清晰的层次结构
- 选中状态明显（▶ 标记）
- 键盘提示清晰
