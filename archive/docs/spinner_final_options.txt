# 旋转动画选项（正方形轨迹）

## 选项 A：方块角落旋转（4帧）
```
▘ -> ▝ -> ▗ -> ▖ -> ▘
```
最简洁，4个角依次点亮

## 选项 B：弧形角落（8帧）
```
◜ -> ◠ -> ◝ -> ◞ -> ◟ -> ◡ -> ◞ -> ◜
```
圆角方块，8个位置

## 选项 C：旋转线条（4帧）
```
│ -> ╱ -> ─ -> ╲ -> │
```
线条旋转，简单经典

## 选项 D：方框旋转（4帧）
```
◰ ◳ ◲ ◱
```
方框四分之一依次亮起
