# 动画方案设计（多个选项）

## 方案 A：极简主义 - 单点变化

**理念：** 简洁、统一、只靠颜色和微妙变化区分

### Read（信息获取）
```
● → ⬤ → ● → ⬤  (呼吸式，蓝色)
```

### Write/Edit（文件修改）
```
▪ → ▫ → ▪ → ▫  (闪烁，橙色)
```

### Bash（命令执行）
```
◆ → ◇ → ◆ → ◇  (菱形变化，绿色)
```

---

## 方案 B：方向感 - 箭头动画

**理念：** 通过方向传达操作类型

### Read（向内读取）
```
→ ⇒ ⇨ ━  (向右流入，蓝色)
```

### Write（向外写入）
```
← ⇐ ⇦ ━  (向左输出，橙色)
```

### Bash（循环执行）
```
↻ ↺ ⟳ ⟲  (旋转箭头，绿色)
```

---

## 方案 C：进度感 - 填充动画

**理念：** 显示任务进行中的感觉

### Read
```
◻ ◧ ◨ ◩  (方块逐渐填充，蓝色)
```

### Write
```
○ ◔ ◑ ◕ ●  (圆形填充，橙色)
```

### Bash
```
▱▱▱ ▰▱▱ ▰▰▱ ▰▰▰  (进度条，绿色)
```

---

## 方案 D：波动感 - 能量传递

**理念：** 像电波一样的能量传递

### Read
```
⋯ ∴ ⋰ ⋱  (点阵扩散，蓝色)
```

### Write  
```
˙ · • ∘  (点大小变化，橙色)
```

### Bash
```
⎯ ⎼ ⎽ ⎼  (波浪线，绿色)
```

---
