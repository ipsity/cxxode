# V2 下一版本改进计划讨论

## 现状分析

### 1. 命令功能问题

**现状：**
- `/model` 命令代码**已经存在**（`src/app/commands.cpp:64-69`）
- 命令调度流程：输入 → `submit()` → `user_command()` → `command()`
- 从代码看应该能工作，但用户报告"未知命令 /model"

**可能原因：**
1. 命令处理顺序问题（user_command 先于 builtin）
2. 命令名匹配问题
3. 交互模式初始化问题

**需要调查：**
- 实际测试 `/model` 命令是否真的失败
- 检查命令调度链路
- 查看是否有其他用户遇到同样问题

## 我的初步想法（仅供参考，不做决定）

### 命令功能改进方向：
1. 添加调试模式查看命令调度
2. 增强命令补全和提示
3. 添加命令别名支持
4. 更好的错误提示

### UI 改进方向：
1. 分离输入/输出区域
2. 优化状态栏显示
3. 增加视觉反馈
4. 改进颜色方案

### Model/Provider 改进方向：
1. 交互式模型选择器
2. 模型信息实时显示
3. Provider 配置向导
4. 模型性能统计
