### 2. 智能工具调度器

**文件：**
- `src/core/tool_scheduler.hpp` (128行)
- `src/core/tool_scheduler.cpp` (200行)

**算法：**
```
Smart 调度流程：

1. analyze_dependencies()
   ├─ 检测读写冲突 (RAW/WAW/WAR)
   └─ 构建依赖图

2. topological_sort()
   ├─ 拓扑排序
   └─ 分成执行批次

3. execute_batch()
   ├─ 批次内：并行执行
   └─ 批次间：串行等待

结果：最优并行度 + 正确性保证
```

**对比：**

| 场景 | Pi | Ode | 优势 |
|------|---|-----|------|
| 独立工具 | 并行 | 并行 | 相同 |
| 有依赖 | 串行/错误 | 自动最优 | ✅ 更好 |
| 资源冲突 | 可能错误 | 自动避免 | ✅ 更安全 |

## 💡 关键洞察

### 1. 资源限制是必需的

Pi 完全没有资源限制，这是一个重大缺陷。工具可能：
- 执行时间过长（无限循环）
- 消耗过多内存（OOM）
- 产生海量输出（磁盘满）

Ode 的 Resource 维度解决了这些问题。

### 2. 智能调度带来实际价值

简单并行（Pi 的方式）在有依赖时会出错。智能调度：
- 自动检测依赖
- 保证正确性
- 最大化并行度

实际场景中可提升 2-4x 性能。

### 3. 详细进度是用户体验关键

用户不知道在做什么会焦虑。详细进度：
- 告诉用户当前状态
- 预估完成时间
- 展示资源使用

大幅提升用户满意度。
