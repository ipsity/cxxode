## 📋 新增快捷命令（7个）

### 文件操作
1. **`/ref <file>`** - 快速查看编辑
   - 自动完成：Read → Edit → Write

### 搜索定位
2. **`/search <pattern>`** (别名: `/s`)
   - 自动完成：Grep → Read 匹配文件

### 智能修复
3. **`/fix [file]`** - 智能检查修复
   - 分析错误并自动修复

### 开发流程
4. **`/test [pattern]`** (别名: `/t`)
   - 运行测试并显示结果

5. **`/build`** (别名: `/b`)
   - 自动检测构建系统并构建

6. **`/run [args]`** (别名: `/r`)
   - 运行程序，可选参数

7. **`/commit [msg]`** (别名: `/c`)
   - 智能分析更改并提交
