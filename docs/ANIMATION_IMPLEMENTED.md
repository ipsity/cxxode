# 动画和配色系统实现完成

## 实现的功能

### 三种动画类型

1. **呼吸动画**（Read/Write/Edit/Grep/Glob）
   - 帧序列：`● → ⬤ → ● → ○`
   - 间隔：200ms
   - 效果：点的大小呼吸变化

2. **线旋转**（Bash）
   - 帧序列：`- → \ → | → /`
   - 间隔：150ms
   - 效果：经典旋转线条

3. **点旋转**（默认/Thinking/其他）
   - 帧序列：`⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧`
   - 间隔：100ms
   - 效果：Braille 点旋转

### 配色方案（深色主题）

| 工具 | 颜色 | RGB | 说明 |
|------|------|-----|------|
| Read | 蓝色 | (79, 193, 255) | 信息获取 |
| Write | 橙色 | (206, 145, 120) | 文件创建 |
| Edit | 黄色 | (220, 220, 170) | 文件编辑 |
| Bash | 绿色 | (78, 201, 176) | 命令执行 |
| Grep/Glob | 青色 | (78, 201, 176) | 搜索操作 |
| 默认 | 灰色 | (200, 200, 200) | 其他操作 |

## 使用效果

```
● Read src/main.cpp        [蓝色呼吸]
● Write config.json        [橙色呼吸]
- Bash npm test            [绿色线旋转]
⠋ Thinking...              [灰色点旋转]
```

## 实现细节

- **函数**：`spinner_with_color(time, tool_name)`
- **自动选择**：根据工具名自动选择动画和颜色
- **ANSI 颜色**：使用 RGB 真彩色（24-bit）
- **性能**：轻量级，无额外开销
