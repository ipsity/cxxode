## ✅ 实现特点

### 1. 固定显示数量
```cpp
constexpr size_t MAX_VISIBLE = 6;  // 固定显示 6 个命令
```
- 不再显示所有命令
- 窗口大小固定
- 界面整洁

### 2. 滚动窗口机制
```
示例（20 个命令）：

选中 1：显示 ▶1 2 3 4 5 6
选中 2：显示 1 ▶2 3 4 5 6
选中 3：显示 1 2 ▶3 4 5 6
选中 4：显示 1 2 3 ▶4 5 6
选中 5：显示 1 2 3 4 ▶5 6
选中 6：显示 1 2 3 4 5 ▶6
选中 7：显示 2 3 4 5 6 ▶7  ← 窗口滚动！
选中 8：显示 3 4 5 6 7 ▶8  ← 继续滚动
...
选中 20：显示 15 16 17 18 19 ▶20
```

**核心逻辑：**
```cpp
if (items.size() > MAX_VISIBLE && palette_index_ >= MAX_VISIBLE - 1) {
    // 当选中项到达第 6 个位置时，开始滚动
    start_index = palette_index_ - (MAX_VISIBLE - 1);
    // 保持选中项在窗口底部
}
```

### 3. 循环选择
```cpp
// 已有实现（interactive_input.cpp）
case key_kind::down:
    palette_index_ = (palette_index_ + 1) % items.size();
```

**行为：**
- 1 → 2 → 3 → ... → 20 → 1 → 2 → ...
- 无限循环
- 到达末尾自动回到开头

### 4. 视觉改进

**选中标记：**

### 5. 常驻显示

**实现：**
- 1000ms 延迟消失

- 防止突然消失

## 🔧 技术实现

### 核心算法
```cpp
// 计算窗口起始位置
size_t start_index = 0;
if (items.size() > MAX_VISIBLE && palette_index_ >= MAX_VISIBLE - 1) {
    start_index = palette_index_ - (MAX_VISIBLE - 1);
    if (start_index + MAX_VISIBLE > items.size()) {
        start_index = items.size() - MAX_VISIBLE;
    }
}

// 渲染可见范围
for (size_t i = 0; i < visible_count; ++i) {
    size_t item_index = start_index + i;
    bool on = item_index == palette_index_;
    // 渲染命令...
}
```
