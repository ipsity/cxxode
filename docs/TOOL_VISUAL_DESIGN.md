# 任务动效和配色设计方案

## 设计理念
- **不同任务类型使用不同的视觉语言**
- **动效传达任务性质**（读取、修改、执行、思考）
- **颜色强化语义**（信息、警告、执行、成功、错误）

---

## 动效设计

### 1. Read 操作（读取文件）
**动画：** 扫描线效果
```
⎯ → ⎯⎯ → ⎯⎯⎯ → ⎯⎯⎯⎯ (横线逐渐增长)
```
**颜色：** 蓝色（#4fc1ff）
**寓意：** 扫描、获取信息

### 2. Write 操作（写入文件）
**动画：** 脉冲点
```
● → ◉ → ⬤ → ◉ → ● (点大小变化)
```
**颜色：** 橙色（#ce9178）
**寓意：** 写入、创建

### 3. Edit 操作（编辑文件）
**动画：** 闪烁光标
```
▌ → ▐ → ▌ → ▐ (光标左右移动)
```
**颜色：** 黄色（#dcdcaa）
**寓意：** 编辑中

### 4. Bash 操作（执行命令）
**动画：** 旋转齿轮
```
⠁ → ⠂ → ⠄ → ⡀ → ⢀ → ⠠ (6帧旋转)
```
**颜色：** 绿色（#4ec9b0）
**寓意：** 进程运行

### 5. Grep/Glob 操作（搜索）
**动画：** 扫描雷达
```
◜ → ◝ → ◞ → ◟ (圆形扫描)
```
**颜色：** 青色（#4ec9b0）
**寓意：** 搜索、扫描

### 6. 思考中（Thinking）
**动画：** 波浪
```
⠁ → ⠈ → ⠐ → ⠠ → ⡀ → ⢀ (波浪传播)
```
**颜色：** 紫色（#c586c0）
**寓意：** AI 思考

### 7. 默认/其他
**动画：** 简单旋转
```
⠋ → ⠙ → ⠹ → ⠸ (经典旋转)
```
**颜色：** 灰色（#d4d4d4）

---

## 状态颜色

### 执行中
- **Read**: `#4fc1ff` (蓝)
- **Write**: `#ce9178` (橙)
- **Edit**: `#dcdcaa` (黄)
- **Bash**: `#4ec9b0` (绿)
- **Search**: `#4ec9b0` (青)
- **Think**: `#c586c0` (紫)

### 完成状态
- **成功**: `✓` + `#4ec9b0` (青绿)
- **失败**: `✗` + `#f48771` (红)
- **取消**: `⊘` + `#6a6a6a` (灰)
- **超时**: `⏱` + `#ce9178` (橙)

## 实现结构

```cpp
struct tool_visual {
    std::vector<const char*> frames;
    int frame_count;
    int frame_delay_ms;
    const char* color_code;  // ANSI color
};

std::map<std::string, tool_visual> tool_visuals = {
    {"Read", {
        {.frames = {"⎯", "⎯⎯", "⎯⎯⎯", "⎯⎯⎯⎯"},
         .frame_count = 4,
         .frame_delay_ms = 200,
         .color_code = "\033[38;2;79;193;255m"}  // 蓝色
    }},
    {"Write", {
        {.frames = {"●", "◉", "⬤", "◉"},
         .frame_count = 4,
         .frame_delay_ms = 150,
         .color_code = "\033[38;2;206;145;120m"}  // 橙色
    }},
    // ... 其他工具
};
```
