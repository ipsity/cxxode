# 快速配置 API 密钥

## 方法 1：使用 login 命令（推荐）

```bash
ode login anthropic
# 输入你的 API 密钥: sk-ant-...
```

## 方法 2：设置环境变量

### PowerShell（永久）:
```powershell
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_API_KEY', 'sk-ant-你的密钥', 'User')
```

### PowerShell（临时）:
```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-你的密钥"
```

### CMD:
```cmd
setx ANTHROPIC_API_KEY "sk-ant-你的密钥"
```

## 获取 API 密钥

1. 访问：https://console.anthropic.com/settings/keys
2. 创建新密钥
3. 复制密钥（以 sk-ant- 开头）
4. 使用上面的方法配置

## 验证配置

```bash
# 重启终端后
ode "你好"
# 应该正常工作
```
